# 🌎 Orbital Flood Watch

> **"Alerta • Monitora • Protege"**

Sistema inteligente de monitoramento climático e alerta preventivo para enchentes, combinando **Edge Computing**, **sensores ambientais** e conceitos inspirados na **Indústria Espacial**.

---

## 🚀 Sobre o Projeto

O **Orbital Flood Watch** foi desenvolvido para a **Global Solution 2026 da FIAP**.

A proposta busca reduzir os impactos causados por enchentes através da coleta de dados ambientais em tempo real, permitindo identificar situações de risco e emitir alertas preventivos para comunidades vulneráveis.

Inspirado em sistemas de monitoramento utilizados por satélites e centros meteorológicos, o projeto demonstra como tecnologias embarcadas podem auxiliar na prevenção de desastres naturais.

---

## 🎯 Objetivo

Desenvolver uma solução capaz de:

- 📡 Monitorar condições ambientais continuamente
- 🌧️ Identificar riscos de enchentes
- 🚨 Emitir alertas preventivos
- 🏘️ Auxiliar comunidades vulneráveis
- 🛡️ Apoiar ações da Defesa Civil

---

## ⚠️ O Problema

As enchentes estão entre os desastres naturais mais frequentes do Brasil.

Todos os anos milhares de pessoas sofrem com:

- Perda de moradias
- Danos materiais
- Interrupção de serviços essenciais
- Deslocamento de famílias
- Riscos à vida humana

Grande parte desses impactos poderia ser reduzida com sistemas de monitoramento e alerta antecipado.

---

## 💡 Nossa Solução

O Orbital Flood Watch funciona como uma estação inteligente de monitoramento.

Através da leitura contínua de sensores ambientais, o sistema identifica situações de risco e informa rapidamente os usuários.

### Principais Recursos

✅ Monitoramento em tempo real

✅ Identificação de riscos

✅ Alertas visuais e sonoros

✅ Integração com sistemas de prevenção

✅ Aplicação inspirada em tecnologias espaciais

---

## 🔧 Componentes Utilizados

| Componente | Finalidade |
|------------|------------|
| Arduino Uno | Controle principal |
| Sensor Ultrassônico HC-SR04 | Medição de nível |
| LEDs | Indicação visual |
| Buzzer | Alerta sonoro |
| Protoboard | Montagem do circuito |
| Resistores | Proteção dos componentes |

---

## ⚙️ Funcionamento

### 🟢 Nível Seguro

- LED Verde ativo
- Sistema operando normalmente

### 🟡 Estado de Atenção

- LED Amarelo ativo
- Possível aumento do risco

### 🔴 Estado de Perigo

- LED Vermelho ativo
- Buzzer acionado
- Alerta emitido
